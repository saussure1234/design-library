# odrive_s05 の再現

目標: O-DRIVE 追手門学院 の講師インタビュー・セクション
方法: 目標スクショと自分の描画を重ねて差分を測り、一致するまで直す（`scripts/repro.py`）

| 版 | score | ズレ16超 | 直したこと |
|---|---|---|---|
| v1 | 24.25 | 13.8% | 目分量で組んだ |
| v2 | 37.63 | 35.9% | `font-feature-settings:"palt"` を入れて3行になった（が写真の切り出し位置を間違えて悪化） |
| v3 | 10.85 | 7.9% | 写真の実測位置 x294/y34 で切り直し／見出し16px・行間1.375（実測 行ピッチ22px・字面高17px） |
| v4 | **9.80** | **7.4%** | 自分の描画も測り、行位置の差ぶんだけpxで補正 |

## 分かったこと

- **日本語は `font-feature-settings:"palt" 1` が無いと約物が全角のままで、1行の文字数が変わる。**
  これが無いと行数が increase して、レイアウトが根本的にずれる。最初の失敗はこれ。
- 目標も自分も**同じ物差しで測る**と、直す量がpx単位で決まる。目で合わせない。
- 残差の大半は**写真そのものの階調**と**ゴースト文字の位置**。文字とカードはほぼ一致。
