# design-library

LPデザインの資産庫。**実例 / 実装 / 判定ルール**の3点セットで溜める。

- `docs/` … 選べるカタログ（GitHub Pagesで公開）
- `index.csv` … 検索用の索引（id, site, url, category, image, picked, note）
- `parts/` … 検証済みの実装（impl.html / rules.yml / notes.md）
- `brands/` … 案件ごとのトークン（色・書体・角丸を実測）

## 使い方
1. カタログでセクションを選び、**IDをコピー**
2. 「このIDのここを真似して」と指示
3. 実装 → 撮影 → 自己採点 → 修正
4. 上手くいったものを `parts/` に3点セットで保存
