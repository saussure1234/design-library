# LP Design System

クライアント向けLPを組むためのトークンと判定基準。

## 中身

| | |
| --- | --- |
| `styles.css` | トークンとWebフォントの入口。これ1本を読めばよい |
| `tokens/` | 色・級数・余白。**各値に、どう実測して決めたかを併記してある** |
| `guidelines/` | 判定基準を目で見える形にした4枚。実装はこれで検算する |
| `SKILL.md` | 守るべき事実と、やってはいけないこと |

## 値の出どころ

掲載サイト（MUUUUU / SANKOU）のスクリーンショットをPNGとして測って決めている。
推測値は入れていない。根拠は各トークンのコメントにある。

- 地の輝度 0.872 … 実測 067=0.867 / 072=0.876 / 茗溪学園=0.872 の帯域から
- 濃地の輝度 0.142（白文字との比5.48）… TOPCON実測 0.140 / 比5.52 と同等
- スクリムの濃さ … 白抜きで比3.0を満たす条件から逆算（背景輝度0.30以下）

## 使い方

1. `SKILL.md` の「守るべき事実」を先に読む
2. ベンチマークを**実寸**で開いて分解する（サムネで判断しない）
3. 数値は**スクリプトで測る**。目分量の値をファイルに書かない
4. 借りられないものは「借りない」と明記する
5. 実装したら `guidelines/` の4観点で検算する
