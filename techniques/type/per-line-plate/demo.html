A. 横組み：1行＝1枚の面に載せ、段差・しっぽ・ベタ影で声にする

普通の場合

ここに見出しが入って、
2行目はここ。

本文がここに入ります。見出しは1枚の帯にまとまり、下に罫が1本引かれています。

2行を1枚の帯に入れて下に罫。整ってはいるが、書かれた文章のままで誰の声にも聞こえない。

この工夫

ここに見出しが入って、

2行目はここ。

行ごとに文字幅ぴったりの面。1px枠＋右下4pxのベタ影、1行目の右下だけにしっぽ、2行目は14px左へずらして短く切る。

B. 縦組み：帯3本を階段状に下げ、上端を写真の上辺に乗り出させる

普通の場合

ひとつめ、ふたつめ、みっつめ。

1本の横帯に3語をまとめ、写真の内側に収める。読める順番は1本きりで、リズムは生まれない。

この工夫

ひとつめ、

ふたつめ、

みっつめ。

語ごとに縦組みの柱へ。右から左へ 0 / 28 / 56px と下端を階段状に下げ、上端は写真の上辺から乗り出させる。
