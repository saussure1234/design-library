### 今日いちばん効いた3つ

**1. v12→v13：級数ではなく区切りが犯人だった**

v12は「3行を2行にする」ために級数を下げた。変わらなかった。
実測すると答えは一目だった。

```
いまの区切り 11字 / 13字 / 15字
  44px → A+B=1049px  B+C=1210px
使える幅は 925px（左余白72 〜 写真の左端997）
→ どの2つを繋いでも入らない。3行になるのは必然
「、」で2つに切れば 前24字=1049px。38pxに落とせば906pxで入る
```

推測でパラメータを動かすと1回無駄になる。先に測れば1回で済む。

**2. v14：実測が全部OKなのに壊れていた**

はみ出し0・衝突0・下端ずれ0。数字は満点。
だが**写真が左に飛んでいた**（人物の右端が400px＝画面の左寄り）。
position:absolute をやめてgridにした瞬間、DOMの順が列の順になったため。

→ **数字で通っても、スクショを見ないと分からない壊れ方がある。**
　 逆に v20 の「語中で割れ★」は検査側のバグだった（矩形の"数"で
　 数えていたので、中に`<span>`がある行を2行と誤検知）。
　 topの違いで数え直したら全幅で1行ずつ。**測る側も疑う。**

**3. v17：ベンチマークの「何を」借りるか**

「見出しは2行」は067・072から借りた目標だった。
だがあの2本の見出しは約20字、ESL clubは39字。

**数字52px > 見出し36px** で主役が入れ替わっていた。

**「見出しが画面で一番大きいこと」**。
借りるべきは後者だった。→ 3行に戻して54pxに上げた。
