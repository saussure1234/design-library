About the code

  • Each file is the live page saved from the browser, so it uses the same Tailwind classes and components as the current build.
  • Scripts are removed and image paths point to https://samurai-style.tokyo, so each file opens on its own.
  • Do not copy the <style> blocks id="mock-utils-base", id="mock-fix" and id="mock-utils", or the _next/ folder (a copy of the live CSS and fonts). They are only for this preview.
  • Change the Japanese (JA) version only. Leave ID and EN as they are.

Not part of this change

  • Do not delete the old pages (/marketing-support, /indonesia-offshore, /newbusiness-pmo). Only their cards leave the service list.
  • The service cards on the TOP page stay as they are.
