# 雰囲気6型 LPテンプレ ─ 共通ブリーフ

6本は**それぞれ個別に作り込む**（骨格の共通化はしない方針）。
ただし**中身は6本で完全に同一**にする。そうしないと「雰囲気の違い」ではなく
「コピーの違い」を見比べることになり、型を選ぶ判断材料にならない。

---

## 商材（業種が分からないダミー）

| | |
| --- | --- |
| 商材 | 法人向けの業務サービス。**業種は特定しない** |
| 製品名 | **Moodly**（仮名。**納品前に必ず差し替える**） |
| 読み手 | 事業会社の担当者 |

業種を出すと「雰囲気の違い」ではなく「業種の違い」を見比べることになる。
だから商材は意図的に空にしてある。

**書いてはいけないもの**（数字を作らない）

導入社数・継続率・削減率・満足度・受賞歴・メディア掲載・企業ロゴ・お客様の声。
これらは**空き枠（スロット）として置く**。枠があること自体が
「ここに実績が入ります」という納品物になる。

---

## コピー（6本すべて一字も変えない）

実測済みの上限に合わせている：**見出し2行＋リード2行＋短句3＋CTA1**。
これ以上増やすと日本語が崩れる（2026-09-01 の6枚で確認）。
見出しは1行9文字以内（375pxで26pxの見出しが入る上限）。

| 場所 | 文 | 全角 |
| --- | --- | --- |
| ロゴ | Moodly | — |
| 見出し | やり方は変えずに、<br>手間だけ減らす。 | 9 / 8 |
| リード | いまお使いのものを、そのまま持ち込めます。<br>作り直しも、覚え直しも要りません。 | 21 / 17 |
| 短句1 | そのまま移行できる | 9 |
| 短句2 | 手間は自動で減る | 8 |
| 短句3 | 変更に追従する | 7 |
| CTA | 資料を見る | 5 |

**副CTA**（本文中に必ず1つ置く）：`まず資料を見る`
→ 静かな雰囲気（クール・落ち着き）は本文CTAが消えやすいと実測で判明しているため、
固定要素として扱う。

## 配色（6型すべて共通・1セットだけ）

**色は固定する。** 型ごとに色を変えると、比較したときに
「雰囲気の差」と「色の差」が混ざって、何を選んでいるのか分からなくなる。

さらに実務上、**実案件ではクライアントのブランド色に差し替わる**。
つまりテンプレに求められるのは「色に依存せずに雰囲気が出せること」。
色を固定するのは制約ではなく、**テンプレの実力を測る条件**。

| 役割 | HEX | HSL | 白文字 | 備考 |
| --- | --- | --- | --- | --- |
| 地 | `#ffffff` | hsl(0,0%,100%) | — | 6型とも白地 |
| 構造色 | `#1f2328` | hsl(213,13%,14%) | 15.80 | ほぼ無彩色の墨。どの雰囲気にも寄らない |
| CTA | `#c15610` | hsl(24,85%,41%) | 4.56 | 白文字4.5:1の上限。構造色と色相170°差 |
| 中性 | `#6b7280` | hsl(220,9%,46%) | 4.83 | |
| ティント | `#f4f5f7` | hsl(220,16%,96%) | — | 節の交互に使う |

検証：CTAの白文字4.56 / 構造色の白文字15.80 / 中性を白地に4.83 /
CTAと構造色の差3.47 / 色相差170°。**NG 0件。**

### 色が同じなら、何で雰囲気を出すのか

**面積の配分と、色以外の全部。** 同じ5色でも、どこにどれだけ使うかで別物になる。

| 効かせ方 | 例 |
| --- | --- |
| 濃色の面積 | クールは構造色を大きく敷く／誠実は罫だけ |
| 角丸 | ポップ 16px ／ 誠実 0px |
| 影 | やわらか は柔らかく広い／クールは無し |
| 余白 | 落ち着き は倍取る |
| 字の太さと大きさ | 元気 900・大／落ち着き 400・小 |
| 装飾 | ポップは図形あり／誠実は無し |
| 写真の扱い | 元気は全面／クールは人物なし |
| 罫の使い方 | 誠実は罫で仕切る／やわらかは罫を使わない |

🚨 **ポップは色が主役の雰囲気なので、色を固定すると一番不利。**
形・角丸・装飾だけでポップに見せられるかが、この型の勝負どころになる。

## セクション構成（6本共通・順番も同じ）

業種が出ないよう、見出しだけを置いて中身はスロットにする節を多くしている。

| # | 節 | 中身 |
| --- | --- | --- |
| 1 | **hero** | 見出し / リード / 短句3 / CTA |
| 2 | **課題** | 3つ。「いまのやり方に手間がかかる」「引き継ぎが人に依存する」「変更のたびに作り直す」 |
| 3 | **できること** | 4つ。「そのまま持ち込める」「手間を自動で減らす」「変更に追従する」「必要な人だけに渡す」 |
| 4 | **導入の流れ** | 3ステップ。「いまの状態を渡す」→「合わせて整える」→「そのまま使い始める」 |
| 5 | **導入実績** | 🔲 スロット（企業ロゴ・数値） |
| 6 | **料金** | 🔲 スロット（表） |
| 7 | **お客様の声** | 🔲 スロット |
| 8 | **FAQ** | 4問。「移行にどれくらいかかりますか」「いまのものは使えますか」「途中でやめられますか」「サポートはありますか」 |
| 9 | **CTA** | 見出し＋ボタン |
| 10 | **footer** | |

**答えは書かない。** FAQの答え・料金・実績は、業種が決まってから入れる箇所。
テンプレでは**設問と枠だけ**置く。

## 写真の枠（6本共通の仕様）

雰囲気によって「人物あり／なし」が変わるので、**枠の仕様だけ**先に決めておく。

| 枠 | 比率 | 中身 |
| --- | --- | --- |
| hero 主要 | 4:3 または全面 | 人物バストアップ、または抽象/建築 |
| できること | 1:1 ×4 | アイコン（線画・自作SVG） |
| 導入の流れ | 16:9 ×1 | 画面キャプチャ相当（いまはスロット） |

## 6型の定義

| # | 名前 | 一言 | 効かせ方 |
| --- | --- | --- | --- |
| 01 | 元気 | 人の顔と色でぐいぐい押す。温度が高い | 熱い・力強い・躍動感 |
| 02 | やわらか | 角がなく体温がある。安心して入れる | 温かい・やさしい・ナチュラル・和モダン |
| 03 | 誠実 | 飾らず要る情報を正しく並べる。信用させにいく | 実直・素朴・信頼感・公的・事務的・整然・職人 |
| 04 | クール | 色を絞り文字で見せる。硬くて都会的 | 硬派・無機質・硬質・かっちり・知的 |
| 05 | 落ち着き | 声を張らない。余白が広く静かで高そう | 上品・高級・端正・繊細・モード |
| 06 | ポップ | 色と形が跳ねている。見ていて楽しい | かわいい・おしゃれ・軽やか・カラフル・レトロ |

**優先順**：04 クール → 03 誠実 → 02 やわらか → 05 落ち着き → 01 元気 → 06 ポップ
（本人の分類件数：クール15・元気7・やわらか6・落ち着き6・誠実5・ポップ5。
クールが最多かつ既にコード化済み）
