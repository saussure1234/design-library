# 雰囲気6型 FV 生成プロンプト

投げ先：ChatGPT（画像生成）／**1スレッドで6連投**。
1通目だけフル指定、2通目以降は「雰囲気だけ差し替え」。

**改行を入れない。`　■` で項目を区切って1行で投げる**
（ブラウザ操作だと改行がEnter送信になる。1行でも読み取り精度は落ちなかった）。

---

## 前回からの変更点

| | 変更 | 理由 |
| --- | --- | --- |
| 1 | 商材を**業種が分からない**ものにした | 「脆弱性診断」だと業種が出て、雰囲気の比較を邪魔する |
| 2 | 固定部に **横長16:10** を明記 | 画角が 1.41 / 1.50 / 1.78 の3種にバラついた |
| 3 | 固定部に **本文にもCTAボタンを1つ** を明記 | クール・落ち着きの2枚でCTAが消えた |
| 4 | 固定部に **地は白** を明記 | 濃色を主色にすると元気が黒に溶けた |
| 5 | 固定部に **色を変えるな／面積の配分で雰囲気を出せ** を明記 | 色が変わると比較にならない |

**色は6枚とも同じ。** 型ごとに色を変えると、比較のときに「雰囲気の差」と
「色の差」が混ざる。実案件ではブランド色に差し替わるので、
**色に依存せず雰囲気を出せるか**がテンプレの実力。

## 差し替える6行

### 01 元気
```
元気。人の顔と色でぐいぐい押してくる。温度が高い。熱い・力強い・躍動感。
```

### 02 やわらか
```
やわらか。角がなくて、体温がある。安心して入っていける。温かい・やさしい・ナチュラル・和モダン。
```

### 03 誠実
```
誠実。飾らずに、要ることを正しく並べる。信用させにいく。実直・素朴・信頼感・公的・事務的・整然・職人。
```

### 04 クール
```
クール。色を絞って、文字で見せる。硬くて都会的。硬派・無機質・硬質・かっちり・知的。
```

### 05 落ち着き
```
落ち着き。声を張らない。余白が広くて、静かで高そうに見える。上品・高級・端正・繊細・モード。
```

### 06 ポップ
```
ポップ。色と形が跳ねている。見ていて楽しい。かわいい・おしゃれ・軽やか・カラフル・レトロ。
```

🚨 **ポップは色が主役の雰囲気なので、色を固定すると一番不利。**
形・角丸・装飾だけでポップに見せられるかが勝負どころ。
1枚目が弱ければ「色は変えずに、形と装飾だけでもっと跳ねさせて」と追い足す。

## 生成後にやること

**FVだけ生成する。** 10節×6型＝60枚は非現実的で、本人の実測でも「LP丸ごとは質が落ちる」。

```
FV 6枚を生成
   ↓
1枚ずつ実測（色は最頻色／サイズは字送り／背景がグラデなら差分で測る）
   ↓
角丸・影・余白・字の太さ・濃色の面積比を「トークン」として抽出
   ↓
以降の9節はそのトークンでコード側で組む
   ↓
追加で生成が要るのは人物・抽象の写真だけ
```

色は固定なので、**実測で拾うのは形と量**（角丸のpx・影のぼかしと不透明度・
節の上下パディング・字の太さと大きさ・濃色が占める面積比）。
