4つの特徴：案3の動きを、いまの図で（2案）

前回の案3（左の図は止めたまま描き変わり、右の4項目を読むと図が切り替わる）の仕組みはそのまま、図だけをいまトップに入っているアイソメの図4枚に差し替えました。A と B の違いは図の色と地だけです。文は本番のまま。

A 紺の窓（トップと同じ図）B 明るい紙（塗り替えた図）
A左の窓は紺のまま。図はいまのトップと同じ参考：Attio「The intelligent system that never sleeps」＋ Ramotion「At the intersection of product and brand」
この案：地は生成り。左に、いまのトップの特徴カードと同じ紺の窓を止めて置き、右の4項目をスクロールで読む。読んでいる項目に合わせて窓の中の図が入れ替わり、入れ替わるたびに図の動きが頭から始まる。窓の左下の線は今どこを読んでいるかの印。スマホは各項目の上に図を置く。

FEATURES

４つの特徴

01 / 04

新規事業立ち上げ経験に基づくコミットメント

所属メンバーは新規事業における立て付けから立ち上げまでの経験を保有。企画フェーズにおける顧客とプロダクトの仮説設計から開発、マーケティング施策立案から各種クリエイティブ制作までを高品質かつワンストップで支援が可能です。

02 / 04

海外経験に基づく多言語対応

海外生活経験が長く、英語・インドネシア語堪能なメンバーが複数在籍。顧客獲得のための各種クリエイティブ制作の他、営業資料作成から商談までを一貫して多言語で対応可能です。

03 / 04

多業種経験に基づく構造理解力

医療・半導体・エネルギー・通信・SaaSなどのBtoB、教育・転職・ECなどのBtoCと、幅広い業種での事業企画・マーケティング支援の経験から、複雑な構造においても的確に理解・整理し、成果につながる戦略を立案します。

04 / 04

少数精鋭だから実現できるスピード感

少数精鋭だから実現できるスピード感。幅広いケイパビリティを持つメンバーが少数でチームを運営。コミュニケーションコストが低く、タスクの所在を明確にしてスピーディーにプロジェクトを推進します。

B左は白い紙。図は明るい色に塗り替えた版参考：同上
この案：仕組みは A と同じ。窓を白い紙（細かい点の地）にし、図は以前の特徴案1で作った白〜生成り〜灰の塗り替え版を使う。ページ全体が明るいまま続く。
