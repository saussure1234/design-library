選び抜いた案

総当たり49案から、「割る記号」でよく見る形に寄っていないものを8案。

参考に見た範囲（ロゴ集・素材サイト・制作事例・美術館の所蔵ページ 計18ページ）で多かった形。ここに寄るものは下の総当たりに回した

  1. 斜め一直線で2つに割り、ずらして S に見せる（素材サイトにそのままのテンプレートがある。06もここに近い）
  2. 横縞で何本も切る（夕日・地球儀に見える）
  3. 45°前後の太い帯で割る
  4. 十字・4分割（ボールや円グラフに見える）
  5. 三日月

逆に、ロゴの世界ではほぼ見ないが、美術にはある考え方：①1950年代の絵画の「キャンバスを刃で切り開く」（切っても離さない）→ E4・K3 ②1970年代の建築作品の「家を2つに斬り、片側だけ沈める」→ D4
