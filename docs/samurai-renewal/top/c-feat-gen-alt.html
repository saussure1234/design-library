今の4つ構造理解力スピード感

FEATURES

製図アニメーションの候補

上の段は c-all-gen の今の4つ（そのまま）。その下に「構造理解力」と「スピード感」の差し替え候補を3案ずつ、同じ大きさのパネルで並べています。各パネルは画面に入った時点から1周目が始まります（1周 10〜11秒。歯車だけは回り続けます）。

NOW今の4つ

c-all-gen.html のまま
01 / 04

新規事業立ち上げ経験に基づくコミットメント

所属メンバーは新規事業における立て付けから立ち上げまでの経験を保有。企画フェーズにおける顧客とプロダクトの仮説設計から開発、マーケティング施策立案から各種クリエイティブ制作までを高品質かつワンストップで支援が可能です。

02 / 04

海外経験に基づく多言語対応

海外生活経験が長く、英語・インドネシア語堪能なメンバーが複数在籍。顧客獲得のための各種クリエイティブ制作の他、営業資料作成から商談までを一貫して多言語で対応可能です。

03 / 04

多業種経験に基づく構造理解力

医療・半導体・エネルギー・通信・SaaSなどのBtoB、教育・転職・ECなどのBtoCと、幅広い業種での事業企画・マーケティング支援の経験から、複雑な構造においても的確に理解・整理し、成果につながる戦略を立案します。

04 / 04

少数精鋭だから実現できるスピード感

少数精鋭だから実現できるスピード感。幅広いケイパビリティを持つメンバーが少数でチームを運営。コミュニケーションコストが低く、タスクの所在を明確にしてスピーディーにプロジェクトを推進します。

03構造理解力 — 3案

多業種の複雑な構造を、理解・整理する
案A 構造理解力
03 / 案A

絡まった線の塊が、ほどけて系統図になる

8本の線が1つの塊に絡まっている → 朱の起点から1本ずつ引き出され、BtoB 5本・BtoC 3本の枝に分かれた系統図に整う。

drawStructureA(ctx,t,w,h)
案B 構造理解力
03 / 案B

ばらばらの部品が、分解図から1つの組立図になる

6つの部品が一点鎖線の上に散っている → 順に滑り込んで組み上がり、最後に寸法線が入る。等角図・隠れ線は破線。

drawStructureB(ctx,t,w,h)
案C 構造理解力
03 / 案C

入り組んだ迷路に、1本の筋道が引かれる

迷路の全体を薄い線で一通りたどる → 入口から出口までの1本だけが濃く引かれ、壁は薄く下がる。周ごとに迷路が変わる。

drawStructureC(ctx,t,w,h)

案A スピード感
04 / 案A

長い工程表が、短く束ねられる

受け渡しの矢印と待ちで階段状に伸びた工程表 → 待ちが消えて並行に詰まり、完了点が手前へ。短くなった幅を寸法線で示し、進捗線が一気に走る。

drawSpeedA(ctx,t,w,h)
案B スピード感
04 / 案B

遠回りの線が、最短の1本に張られる

中継点だらけの遠回りを墨の点がのろのろ進む → 線がぴんと張って一直線になり、朱の点が何度も速く駆け抜ける。

drawSpeedB(ctx,t,w,h)

朱の点を付けた小さな歯車が速く回り、噛み合った大きな歯車を回す。ピッチ円・中心線は製図の描き方（一点鎖線）。
