2026-11-26Free・Open 新しい候補

VALUES のアイコンの候補 2

前の候補（案1〜3）はどれも不採用だった Free と Open を、意味が一目で伝わる具体的なモチーフで4案ずつ作り直しました。Flat は決定の円卓。カーソルを合わせると粒がよけます。

Free

各自の責任感の下、場所や時間に捉われず自由に裁量を持って働く

案4 紙飛行機4機がそれぞれの向きへ、ゆらぎながら飛ぶ。後ろに点線の航跡

案5 渡り鳥高さも羽ばたきもばらばらの7羽が、同じ方向へ飛んでいく

案6 地図の点を光が行き来6か所の点を弧でつなぎ、光の粒がその上を渡る（場所に捉われない）

案7 それぞれの速さの時計大きさの違う4つの時計の針が、それぞれの速さ・向きで回る（時間に捉われない）

Open

チーム内では本音で向き合い、人格は否定しない

案4 向き合う吹き出し2つの吹き出しが向き合い、話す側の点が弾み、言葉の粒が相手へ渡る（交互に）

案5 手のひらが開いて光握った手がゆっくり開き、開くと手のひらから光の粒が上へ広がる

案6 向き合う2人2人の間を、上は左から右、下は右から左へ粒が行き来する

案7 幕が開いて光が差す左右の幕が中央から開き、すき間から光の帯が降りる

Flat（決定）

年齢や役職などの上下関係なく接する

決定 円卓同じ大きさの席が、同じ高さで1つの輪に並ぶ（Flat は案2で決定）
