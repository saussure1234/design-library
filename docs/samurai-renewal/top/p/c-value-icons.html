VALUES のアイコンの候補

会社概要と採用の VALUES で使う粒のアイコン。値ごとに3案。太枠が今使っている形。カーソルを合わせると粒がよけます。

Free

各自の責任感の下、場所や時間に捉われず自由に裁量を持って働く

案1（今）群れで飛ぶ粒の群れが、思い思いの向きへ流れていく

案2 風船が上がる色の違う風船が、それぞれの速さで上がっていく

案3 風が流れるくるっと巻く線が、左から右へ流れる

Flat

年齢や役職などの上下関係なく接する

案1（今）1列に並ぶ粒が1本の水平な線にそろい、ゆるく波打つ

案2 円卓同じ大きさの席が、同じ高さで1つの輪に並ぶ

案3 波がおさまって水平に上下に揺れていた波が、平らにそろっていく

Open

チーム内では本音で向き合い、人格は否定しない

案1（今）輪が口を開ける閉じかけた輪の一部が、ゆっくり開いている

案2 扉が開いて光がこぼれる扉が開き、中から光が外へあふれる

案3 花が開くつぼみが、全方向へ花びらを開く
