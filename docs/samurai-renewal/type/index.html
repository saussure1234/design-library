一言
見出しを画面幅いっぱいに。極太・白抜き・巨大な番号・傾けた札で、文字そのものを絵にする。
書体
欧文 Archivo（幅125%・900）／和文の見せ場 Dela Gothic One／本文 Noto Sans JP 500–900／オレンジ #ff4d1f
参考
zajno・instrument（画面幅いっぱいのワードマーク）・rejouice（巨大な社名と小さな文の対比）・studiodumbar（撮れたのはFVの渦だけ。色の熱量のみ参考）
全体節見出しの欧文を画面幅に合わせて自動で特大に＋傾けたシールに日本語
STORY問いの一文を黒帯で特大に。「シグナル」は塗り、「ノイズ」は白抜き
FEATURES巨大な番号 01〜04。白抜きで現れて塗りつぶされ、ホバーでオレンジ
SERVICEサービス名をカード幅いっぱいに。白抜きの番号と傾けたカテゴリ札
MEMBER名前を極太で並べたポスターの索引。写真は傾けた枠、ホバーで名前が白抜き
CONTACTCONTACT US が傾いた黒帯で流れる（塗り／白抜き交互）。太枠のフォームと全幅の送信

確認：PC 1440×900・スマホ 390×844 で上から順に撮影。3案とも横はみ出しなし、本番の文（STORY〜フッター）は画面の文字と突き合わせて欠けなし。
