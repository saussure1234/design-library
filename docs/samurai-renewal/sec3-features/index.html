4つの特徴：明るい地の6案（第3弾）

暗い地をやめ、生成り・白・淡い色面で組み直した案です。強調色は電球の黄色だけ。各案の上に参考サイトの実物の切り抜きを置いています。文は本番のまま。

1 立体の図×4列2 大きな数字3 左に図・右に4項目4 淡い色面のタイル5 窓とコマンド（コード風）6 雑誌の組み・写真1枚
1白い紙の上の立体図。細い罫で4列に区切る参考：Pitch「Slides that are fully editable / Keep every deck on-brand / Set up agentic workflows」
実物：白地に3列。小さな線のアイコン、太字の見出し、灰色の短文だけの静かな並び。
この案：列を4つにして細い縦罫で区切り、アイコンの代わりに今のアイソメ図を白〜生成り〜灰の明るい色に塗り替えて置く。動くのは各図の黒い1個と黄色の1個だけ。マウスを乗せた列だけ白くなり、上に黄色の線が走る。
