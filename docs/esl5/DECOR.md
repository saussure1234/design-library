## 2. ここから出た事実

**現行 esl3 は「装飾ゼロ」群と同じ型。**
白地＋実写＋硬いゴシック＋横書き＋装飾なし。

そして「装飾ゼロ」の5サイトは全部**大人向け**：
日能研関西（採用）／ INCLUSIVE CAMP ／ サンデシカ ／ ISURU（ベビー用品＝買うのは親）／ 天水福祉。
**子どもに向けたサイトで装飾ゼロのものは1つも無い。**

→ 小学生向けに振るなら、装飾を足すこと自体が要件。トーンの好みの話ではない。

## 4. Lottie の担当箇所

**浮遊オブジェ（4/18）だけ。**

| 使う | 使わない |
| --- | --- |
| 図形・線を自作して動かす（B案） | LottieFiles のイラストを借りる（A案） |

理由：LottieFiles から16本落として全部見た。全部**外国製の多色フラットイラスト**で、ESL clubの白／緑／実写／硬ゴシックと同居しない。
色の機械差し替え（C案）は技術的には動くが、**人物の肌と髪まで緑になる**ので人物入りには使えない。→ `lottie/recolor/` に検証物あり。

ベンチマークの浮遊オブジェも、実物は全部**単純な図形**：
- 020健診 → 紙飛行機（三角2枚の塗り分けだけ）
- 019バディ → 吹き出し（角丸長方形＋三角の尻尾）
- 022ビートル → 切り抜き写真（図形ではない）
- 005日暮里 → 切り抜き小物（図形ではない）

→ **自作で足りる。**

## 5. 装飾の実寸（拡大して測ったもの）

サムネや縮小画像では出なかった差。**実寸で見て初めて分かった。**

| ベンチマーク | 測った値 | ESL clubに移植できるか |
| --- | --- | --- |
| **020 紙飛行機** | **黒2pxの輪郭線がある**／横から見た薄い形で後端が2つに割れる／くすんだパステル（クリーム黄・水色・サーモン）／幅=画面の**7.6%**／角度バラバラ3機 | **✗ 不採用。** 輪郭線＝線画イラストの世界観が前提。周りが実写のESL clubに混ぜると浮く |
| **036 緑の五角形** | 幅 **170px = 画面の11.8%**／**不透明100%のベタ**／**写真には重ねない**。白いセクションの上に置き、下端で切れて見える／右端にもう1つ小さいのを添える | **○ 採用。** LITALICO自体が実写＋白地＋硬ゴシックでESL clubと同じ構成 |
| **019 吹き出し** | 幅 **画面の2.6〜7.2%**（中央値3.8%）／**9個以上を散らす**／サイズはバラバラ／空の吹き出し（中に文字なし） | **○ 採用。** 「英語＝しゃべる」の記号。線画と違って世界観を要求しない |

★ 私が最初に外した点（記録として残す）
1. 紙飛行機を**輪郭線なしの塗りだけ**で作った → 矢印に見えた
2. 五角形を**薄く（14%・55%）した** → LITALICOはベタ100%
3. 五角形を**写真に重ねた** → 黄色が子どもの頭に乗って帽子に見えた
4. 吹き出しを**白**にした → クリーム地に埋もれて汚れに見えた。緑の濃淡3段に変更
5. 装飾を**%指定の絶対配置**にした → 画面高が変わると本文にぶつかる。px＋写真カラム紐づけに変更

## 6. 作ったもの

| ファイル | 中身 |
| --- | --- |
| `lottie/own/*.json` | 自作の図形アニメ12本・**合計約15KB**（LottieFilesは1本439KB） |
| `lottie/lf/` | LottieFilesから落とした16本（全部不採用。判断の証拠として残す） |
| `lottie/recolor/` | 色を機械差し替えした5本（人物の肌まで緑になるので不可、の証拠） |
| `build.py` | index.html から fv_a / fv_b を生成。**土台を直したら必ず再実行する** |
| `check.py` | 6つの画面幅で衝突・はみ出し・埋没を検査。**目で見る前に必ず通す** |
| `fv_a.html` | 案A：クリーム地＋緑の吹き出し5個（019型） |
| `fv_b.html` | 案B：白地のまま＋緑の五角形2つ（036型） |

## 7. 土台(index.html)で見つけて直したバグ

装飾とは無関係に元から入っていたもの。

| # | 症状 | 原因 | 直し方 |
| --- | --- | --- | --- |
| 1 | ヘッダーCTAが**黒い箱**（文字が見えない） | `.header-nav a`(詳細度0,1,1) が `.btn-primary`(0,1,0) に勝ってネイビー地にネイビー文字 | `.header-nav a.btn-primary{color:#fff}` を追加。コントラスト 1.0 → **14.81** |
| 2 | 縦書きの副題が**写真に食い込む** | `.fv-vertical` が `right:-32px` の絶対配置。列幅528pxに円480pxで**40px食い込む** | 絶対配置をやめてフロー（横並び）に。円を400pxへ |
| 3 | 1024pxで**横スクロール24px** | `.point-block{1fr 1fr}` が中身（画像420px・円88px×5）の最小幅に押し負け、列の合計が入れ物936pxを**68px超える** | `minmax(0,420px) minmax(0,1fr)` ＋ 画像・円を可変に |
