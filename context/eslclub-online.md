# ESL club オンライン校 ─ 事業理解

## 誰に
小学生〜高校生の保護者。受験勉強と並走しながら英検合格を目指す層。
英語をこれから始める層と、すでに英検を受けている層の両方。

## 何を売るか
バイリンガル講師によるオンラインのマンツーマンレッスン。
渋谷校（週1回90分 58,300円/月）とオンライン校（週1回45分 33,000円/月）。入会金22,000円。

## 主張（LPで通すべき筋）
1. 高い英検合格率（累計1,000名以上・英検ベースのカリキュラム）
2. 保護者の負担が軽い（スクールマネージャーが計画と共有を担う）
3. 学習効率を向上（バイリンガル講師のマンツーマン）
4. 受験勉強と並行できる（目標級・時期と現在のレベルから作る個別計画）

## 使ってよい数字
- 5級100% / 4級88% / 3級86% / 準2級64% / 2級75%
  注記「2023年度第2回の実績（ESL clubオンライン校）／受験者のうち1次・2次受験双方に合格した生徒の割合」を必ず添える
- 累計1,000名以上を合格に導いた
- 講師は英検1級・TOEFL iBT95点・TOEIC900点レベル以上

## NG
- 「お子様」「保護者様」「生徒様」の漢字表記 → すべて「さま」
- 英検® の商標注記を落とすこと
- 合格率の数字を丸めたり、注記を外して単独で載せること
- 中学生・高校生向けの文言（このLPは小学生〜高校生向け）

## トーン
やさしく、断定しすぎない。保護者に向けた説明口調。
煽らない（「今すぐ」「絶対」は使わない）。

## 写真の使い方
- 勉強している小学生＝学習の場面
- 部活・スポーツ＝「受験勉強と並行」の主張にだけ使う。学習効率の文脈には置かない
- 講師の写真＝マンツーマン・距離の近さの文脈
